# 数据说明

本目录的数据复制自原工作区，上传版路径为 `data/project/`，未修改 CSV 内容。

| 文件 | 数据行数 | 用途 |
| --- | ---: | --- |
| project/train_250.csv | 250 | 训练与开发验证 |
| project/test_50.csv | 50 | 保留的最终测试集 |

字段：`text`（诉求文本）、`label`（六类标签）、`urgency`（紧急程度）、`department`（部门）。

模型开发阶段只使用训练集。不要用测试集拟合 TF-IDF 或选择参数。练习目录下的同名 CSV 属于另一标注版本，未包含在此整理版。

当前材料未明确记录数据的采集来源、授权方式及脱敏流程；不应据此宣称数据已获得公开许可。公开仓库前请由数据负责人补充来源与授权说明，并确认文本可以公开。
